The interface standard between fork steerer tube and frame head tube — typically straight 1-1/8", tapered 1.5" to 1-1/8", or integrated drop-in. The standard must match across frame, fork, and stem or headset.

Published as a categorical string (e.g. "tapered 1.5-1.125in") because manufacturers use overlapping naming — Compatibility Rules compare normalized tokens, not infer fitment.
